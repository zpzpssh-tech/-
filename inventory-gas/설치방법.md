# 올투게더나우 재고관리 — 구글 웹프로그램 설치 방법

프로그램과 데이터가 모두 **대표님 구글 드라이브 안**에 저장됩니다.
비용은 0원이고, 설치한 뒤에는 Claude 없이도 계속 돌아갑니다.

```
[대표님 구글 드라이브]
 └─ 재고DB (구글 시트)
     ├─ 탭: SKU / 기록 / 연결표 / 업로드 / 재고현황   ← 모든 데이터
     └─ 붙어 있는 프로그램 (Apps Script)              ← 화면 + 저장 기능
```

필요한 파일은 이 폴더의 두 개입니다.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 시트를 읽고 쓰는 서버 쪽 코드 |
| `Index.html` | 휴대폰·PC에서 보는 화면 |

---

## 1단계. 재고DB 시트 만들기 (1분)

1. 브라우저 주소창에 `sheets.new` 입력 → 새 구글 시트가 열립니다.
2. 왼쪽 위 제목을 **재고DB**로 바꿉니다.

## 2단계. 프로그램 붙여넣기 (3분)

1. 시트 메뉴 **확장 프로그램 → Apps Script** 클릭 → 새 탭에 편집기가 열립니다.
2. 왼쪽 위 프로젝트 이름을 **재고관리**로 바꿉니다.
3. `Code.gs` 파일:
   - 편집기에 이미 있는 `Code.gs`의 내용을 **전부 지우고**
   - 이 폴더의 `Code.gs` 내용을 통째로 복사해 붙여넣습니다.
4. `Index.html` 파일:
   - 왼쪽 **파일 옆 + 버튼 → HTML** 클릭 → 이름을 **Index** 로 입력 (`.html`은 자동으로 붙음, 대소문자 정확히)
   - 안에 있는 기본 내용을 지우고, 이 폴더의 `Index.html` 내용을 통째로 붙여넣습니다.
5. 위쪽 **💾 저장** 아이콘 클릭 (또는 Ctrl+S).

## 3단계. 처음 한 번 준비 실행 (2분)

1. 편집기 위쪽 함수 선택 칸에서 **setup** 을 고르고 **▶ 실행**.
2. "승인 필요" 창이 뜨면:
   - **권한 검토** → 대표님 구글 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 재고관리(으)로 이동(안전하지 않음)** 클릭
     (대표님이 직접 만든 프로그램이라 구글 심사를 안 받았다는 뜻일 뿐, 문제없습니다)
   - **허용**
3. 아래 실행 로그에 "실행 완료"가 나오면, 시트에 **SKU / 거래처 / 기록 / 연결표 / 업로드** 탭이 생깁니다.
   거래처 탭에는 대표님 판매 채널(쿠팡 로켓배송, 네이버, 쿠팡 CPG·HCK·YCU, 도매 거래처)이 미리 들어가 있습니다.

## 4단계. 웹프로그램으로 배포 (2분)

1. 편집기 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 설정:

   | 항목 | 대표님 혼자 쓸 때 | 직원과 같이 쓸 때 (추천) |
   |---|---|---|
   | 다음 사용자 인증 정보로 실행 | 나 | **웹 앱에 액세스하는 사용자** |
   | 액세스 권한이 있는 사용자 | 나만 | **Google 계정이 있는 모든 사용자** |

4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
   이 주소가 재고관리 프로그램입니다. 휴대폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있습니다.

## 5단계. 직원 추가 (직원과 같이 쓸 때만)

"직원과 같이 쓸 때" 설정은 **재고DB 시트에 공유된 사람만** 데이터를 볼 수 있습니다.
링크가 새어 나가도 시트 권한이 없는 사람은 아무것도 못 봅니다.

1. 재고DB 시트 오른쪽 위 **공유** → 직원 구글 이메일 추가 → **편집자** → 보내기.
2. 직원에게 웹 앱 URL을 보내 줍니다.
3. 직원도 처음 열 때 3단계와 같은 "승인" 화면이 한 번 나옵니다. 같은 방법으로 허용하면 됩니다.

기록 내역의 "기록자" 칸에 각자의 구글 이메일이 남아서 누가 기록했는지 알 수 있습니다.

---

## 처음 쓰는 순서

1. **엑셀 탭 → 내보내기 → '상품(SKU) 목록 · 양식' 엑셀 받기** → 양식에 SKU를 채웁니다.
   (기존에 쓰던 재고 엑셀이 있으면 그대로 올려도 됩니다. 열 제목을 자동으로 찾아 맞춥니다.)
2. **엑셀 탭 → 불러오기 → 상품(SKU) 목록** 으로 올립니다. 기준원가·소매가·도매가도 같이 들어갑니다.
3. 창고 실사 후 **엑셀 탭 → 불러오기 → 현재 재고** 로 시작 재고를 넣습니다.
   ('실사표' 엑셀을 받아 실사수량 칸만 채워 올리면 편합니다.)
4. 그다음부터는 입고(입고단가 포함)·파스토 보내기·로켓 출고·거래처 출고를 그때그때 기록합니다.

## 주요 기능 한눈에

| 기능 | 어디서 | 하는 일 |
|---|---|---|
| 엑셀 불러오기 | 엑셀 탭 | 기존 재고표로 SKU 목록·현재 재고를 한 번에 등록 |
| 엑셀 내보내기 | 엑셀 탭 | 재고 현황, 원가·재고금액, 기록 내역, SKU 목록, 실사표 (.xlsx 또는 시트) |
| 거래처별 단가 | 입출고 기록 → 로켓 출고 / 거래처 출고 | 그 거래처에 직전에 판 단가 자동 입력. 처음이면 소매가/도매가/직접입력 선택 창 |
| 나란히 보기 · 새 창 | 탭 오른쪽 '옆에 띄우기', '새 창' | 두 화면을 한 화면에 나란히, 또는 다른 창으로 |
| 원가 재계산 | 원가·재고금액 탭 | 입고단가로 이동평균원가 계산, 재고금액·판매원가·거래처 이익·조정손익 |

## 프로그램을 고쳤을 때 (업데이트)

Claude가 `Code.gs`나 `Index.html`을 새로 고쳐 드리면:

1. 편집기에서 해당 파일 내용을 새 것으로 바꿔 붙여넣고 저장.
2. 편집기에서 **setup** 을 한 번 더 실행합니다. (새로 생긴 열·탭만 추가되고, 기존 기록은 그대로입니다.)
3. **배포 → 배포 관리 → 연필(수정) 아이콘 → 버전: 새 버전 → 배포.**
   (이렇게 해야 **주소가 바뀌지 않습니다.** "새 배포"를 누르면 주소가 새로 생기니 주의)

## 자주 묻는 것

- **엑셀로 받고 싶어요** → 재고 현황 탭의 **시트로 내보내기** → 시트의 '재고현황' 탭에 저장됩니다.
  시트에서 **파일 → 다운로드 → Microsoft Excel**.
- **백업은요?** → 구글 시트가 자동으로 버전 기록을 남깁니다 (**파일 → 버전 기록**).
  한 달에 한 번 **파일 → 사본 만들기**를 해 두면 더 안전합니다.
- **시트에서 직접 고쳐도 되나요?** → 메모·수량 정도는 괜찮지만, ID·묶음ID 칸은 건드리지 마세요.
  잘못 기록한 건 프로그램의 **기록 내역 → 삭제**로 지우는 게 안전합니다.
- **다른 사람이 기록한 게 안 보여요** → 2분마다 자동으로 불러옵니다. 바로 보려면 오른쪽 위 **새로고침**.
- **느려요** → 기록이 수만 줄이 되면 처음 열 때 몇 초 걸릴 수 있습니다.
  1년치 이상 쌓이면 말씀해 주세요. 지난 기록을 '월말 재고' 한 줄로 묶어 가볍게 만들 수 있습니다.
