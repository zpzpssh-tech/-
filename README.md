# 올투게더나우 이익 장부

네이버·쿠팡(올투게더나우/휴책/유큐어)·기타 사이트 매출에서 수수료·원가·배송비·광고비·고정비를 빼서
**진짜 영업이익**을 보여주는 대시보드입니다. 데이터 파일(CSV)만 바꿔 넣으면 숫자가 다시 계산됩니다.

## 쓰는 법 (3단계)

1. `data/` 폴더의 CSV 파일을 실제 데이터로 바꿉니다. (형식은 아래 표)
2. 터미널에서 한 줄 실행: `python3 scripts/build.py`
3. `dashboard/index.html` 파일을 더블클릭해 브라우저로 엽니다. 인터넷 없이도 열립니다.

> 지금 들어 있는 데이터는 **예시**입니다. `python3 scripts/make_sample_data.py`로 만든 가짜 숫자이며,
> 실제 데이터를 넣을 때는 `data/settings.json`의 `"예시데이터": true`를 지우거나 `false`로 바꿔 주세요.

## 데이터 파일 형식

첫 줄은 열 이름이고, 엑셀에서 "CSV UTF-8"로 저장하면 됩니다.

| 파일 | 열 | 설명 |
|---|---|---|
| `data/sales.csv` | 날짜, 채널, 계정, 상품코드, 주문건수, 판매수량, 매출 | 하루·계정·상품별 한 줄. 날짜는 `2026-01-31` 형식 |
| `data/products.csv` | 상품코드, 상품명, 카테고리, 판매가, 원가, 포장비 | 원가 = 제조단가 + 국제운송 + 관세를 개당으로 |
| `data/costs.csv` | 월, 구분, 항목, 계정, 금액 | 구분은 `고정지출` 또는 `마케팅비`. 계정을 비우면 회사 공통 비용 |
| `data/settings.json` | 계정별 수수료율, 건당배송비 | 쿠팡·네이버 정산 기준으로 수정 |

빌드 스크립트는 열 이름이 빠졌거나, 상품코드·계정 이름이 안 맞거나, 숫자 칸에 글자가 있으면
어느 파일 몇 번째 줄이 문제인지 알려주고 멈춥니다.

## 계산 방식

- **계정 영업이익** = 매출 − 수수료(매출 × 수수료율) − 원가(수량 × (원가+포장비)) − 배송비(주문건수 × 건당배송비) − 그 계정 마케팅비
- **최종 영업이익** = 계정 영업이익 합계 − 공통 마케팅비 − 고정지출
- 월 단위 비용은 선택한 기간에 포함된 날짜 수만큼 비례 배분합니다.
- 상품별 마진에는 광고비를 배분하지 않습니다. (상품별 광고비 데이터가 생기면 추가 예정)

## 폴더 구조

```
data/        매출·상품·비용 CSV, 수수료 설정   ← 대표님이 바꾸는 곳
scripts/     build.py (대시보드 생성), make_sample_data.py (예시 데이터 생성)
templates/   dashboard.html (화면 디자인·계산 로직)
dashboard/   index.html (생성 결과, 브라우저로 여는 파일)
```
