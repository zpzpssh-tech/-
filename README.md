# 올투게더나우 정산 매출 대시보드

네이버·쿠팡 정산 파일을 넣으면 **정산예정금(수수료 빠진 실수령) 기준 매출**을 계산해
보여주는 대시보드입니다. 원가와 고정비를 채우면 영업이익까지 이어서 계산합니다.

## 쓰는 법

1. **네이버 건별 정산내역 엑셀**을 `data/원본/네이버/` 폴더에 넣습니다.
   파일 이름은 자유이며 `2026-09.xlsx`처럼 월별로 두면 관리가 편합니다.
2. **원가관리 엑셀**을 `data/원본/원가/` 폴더에 넣습니다. (가장 최근 파일 하나만 씁니다)
3. **고정지출·마케팅비 시트**와 **네이버 검색광고 리포트**를 `data/원본/비용/` 폴더에 넣습니다.
   파일 이름에 각각 `고정`, `광고`가 들어가야 종류를 구분합니다.
4. 터미널에서 네 줄 실행:
   ```
   python3 scripts/import_costs.py     # 원가관리 엑셀 → 원가·수량
   python3 scripts/import_expenses.py  # 고정비·광고비 → costs.csv
   python3 scripts/import_naver.py     # 정산 엑셀 → 매출
   python3 scripts/build.py            # → 대시보드
   ```
5. `dashboard/index.html`을 더블클릭해 브라우저로 엽니다. 인터넷 없이 열립니다.

처음 한 번은 `pip install openpyxl`이 필요합니다.
`import_costs.py`를 먼저 돌려야 같은 상품이 이름이 바뀌어도 상품번호로 하나로 묶입니다.

## 원가 계산 규칙

원가관리 엑셀의 `원가` 시트(상품번호·옵션정보·원가)와 월별 주문 시트(수량)를 짝지어 계산합니다.
원가를 붙이는 순서는 아래와 같고, 위에서부터 먼저 맞는 것을 씁니다.

| 순서 | 방법 |
|---|---|
| 1 | 상품번호 + 옵션정보가 정확히 같을 때 |
| 2 | 그 상품번호에 옵션 없는 원가가 있을 때 |
| 3 | 색상 표현만 다를 때 (블랙·블루 등을 지우고 비교) |
| 4 | 그 상품번호의 원가가 딱 하나뿐일 때 |

못 찾은 건은 `data/원가_미매칭.csv`에 수량 많은 순으로 적힙니다. 원가관리 엑셀의 `원가` 시트에
그 옵션을 추가하면 반영률이 올라갑니다. 주문상태가 **취소·반품**인 건은 물건이 돌아오므로 원가에서 뺍니다.

## 손익 계산 규칙

| 단계 | 계산 |
|---|---|
| 매출 | 정산예정금 합계 |
| − 상품 원가 | 원가관리 엑셀의 상품번호·옵션별 원가 × 수량 |
| = **매출총이익** | |
| − 택배비 | 주문 건수 × 건당 단가 |
| − 채널 광고비 | `costs.csv`에서 계정이 적힌 마케팅비 (네이버 검색광고) |
| = **기여이익** | 그 채널이 직접 벌어들인 이익 |
| − 회사 공통 마케팅비 | `costs.csv`에서 계정이 빈 마케팅비 |
| − 회사 고정지출 | `costs.csv`의 고정지출 |
| = **영업이익** | |

고정지출과 공통 마케팅비는 네이버·쿠팡 전 채널이 함께 쓰는 비용입니다.
지금은 네이버 매출에만 전부 물려 계산하므로 **영업이익이 실제보다 낮게 나옵니다.**
쿠팡 자료가 들어오면 제대로 나뉩니다. 채널 판단에는 **기여이익**을 보세요.

### 택배비

정산 파일에 배송 방식(N배송/판매자배송) 구분이 없습니다. `data/settings.json`의
`택배비.N배송비율`(0~1)에 실제 비중을 넣으면 두 단가를 섞어 계산합니다.
2026년 1~8월은 대표 확인으로 **전량 N배송(₩3,280)** 을 적용했습니다.

```json
"택배비": { "N배송단가": 3280, "판매자배송단가": 2400, "N배송비율": 1.0 }
```

### 원가를 못 찾은 옵션 채우기

원가관리 엑셀을 직접 고치지 않고도 `data/원가_추가.csv`에 줄을 더하면 됩니다.
`import_costs.py`가 이 파일을 읽어 엑셀 원가에 얹습니다.

```
상품번호,옵션정보,원가,메모
5799070116,✅ 족부 아치 깔창 1쌍: L(250~275mm),500,대표 지정 2026-09-02
```

옵션정보는 `data/원가_미매칭.csv`에 적힌 문자열을 그대로 복사해 넣어야 붙습니다.

## 매출 계산 규칙

네이버 건별 정산내역의 **정산예정금액**을 합산합니다. 정산상태별 처리는 아래와 같습니다.

| 정산상태 | 처리 | 이유 |
|---|---|---|
| 빠른정산 | ＋ 더함 | 실제로 돈이 들어온 건 |
| 일반정산 | ＋ 더함 | 실제로 돈이 들어온 건 |
| 빠른정산 회수 | － 뺌 | 먼저 받은 돈을 네이버가 도로 가져감 |
| 정산후 취소 | － 뺌 | 정산받은 뒤 고객에게 환불해 줌 |
| 정산전 취소 | 제외 | 돈을 받은 적이 없는 건 |

- 정산예정금액은 **네이버 수수료가 이미 빠진 금액**이라 대시보드에서 수수료를 다시 빼지 않습니다.
- 날짜는 **결제일** 기준입니다.
- 정산 파일에는 판매 수량 칸이 없어 **상품주문 한 줄을 1개**로 셉니다. 옵션으로 2개 산 주문은 적게 잡힐 수 있습니다.
- 주문 건수는 주문번호 기준으로 중복을 제거해 셉니다.

## 데이터 파일

| 파일 | 만들어지는 방식 | 설명 |
|---|---|---|
| `data/sales.csv` | 자동 생성 | 날짜·상품별 매출 |
| `data/일별주문.csv` | 자동 생성 | 날짜별 실제 주문 건수 |
| `data/정산요약.csv` | 자동 생성 | 월별 정산상태 반영 내역 (검증용) |
| `data/원가일계.csv` | 자동 생성 | 날짜·상품번호별 수량과 원가 |
| `data/상품매핑.csv` | 자동 생성 | 상품명 → 상품번호. 이름이 바뀐 같은 상품을 하나로 묶는 표 |
| `data/원가_미매칭.csv` | 자동 생성 | 원가를 못 찾은 옵션 목록 |
| `data/products.csv` | 자동 생성 | 상품 목록과 누적 실적 |

`products.csv`는 누적 매출이 큰 상품이 맨 위에 오도록 정렬되며 변환할 때마다 다시 만들어집니다.
`참고_이름수`는 그 상품이 정산 파일에서 몇 개의 이름으로 나타났는지를 뜻합니다.
| `data/costs.csv` | 직접 입력 | 월별 고정지출·마케팅비 |
| `data/settings.json` | 직접 입력 | 계정별 수수료·건당 택배비 |

`products.csv`의 상품코드는 한 번 정해지면 유지됩니다. 새 정산 파일에 새 상품이 나오면
자동으로 코드가 붙고, 이미 채워 둔 원가는 지워지지 않습니다.

## 영업이익까지 보려면 더 필요한 것

1. **월별 고정비와 광고비** — 인건비, 창고·사무실, 물류 솔루션, 채널별 광고비 (`data/costs.csv`)
2. **건당 택배비** — 실제 지급하는 택배 단가 (`data/settings.json`)
3. **원가 미매칭 옵션** — `data/원가_미매칭.csv`의 옵션을 원가관리 엑셀에 추가
4. **쿠팡 계정 정산 파일** — 쿠팡용 변환기를 추가해 같은 규칙으로 합산합니다

## 폴더 구조

```
data/원본/네이버/   정산 엑셀 원본을 넣는 곳
data/원본/원가/     원가관리 엑셀을 넣는 곳
data/              변환된 CSV와 설정
scripts/           import_costs.py, import_naver.py, build.py
templates/         dashboard.html (화면 디자인·계산 로직)
dashboard/         index.html (완성본, 브라우저로 여는 파일)
```
