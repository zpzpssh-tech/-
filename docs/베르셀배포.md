# 베르셀(Vercel)에 올려서 나만 보기

`dashboard/index.html` 을 베르셀에 올리고 **비밀번호로 잠그는** 방법입니다.
무료 플랜으로 됩니다.

## 먼저 알아야 할 것

베르셀 **무료(Hobby) 플랜은 운영 주소를 잠글 수 없습니다.**
베르셀이 제공하는 잠금 기능(Vercel Authentication)은 미리보기 주소에만 걸리고,
실제 주소는 공개로 남습니다. 운영 주소를 잠그려면 Pro 월 $20,
비밀번호 기능은 그보다 훨씬 비쌉니다.

이 대시보드에는 계정별 매출·원가·광고비·마진이 들어 있어서 공개되면 안 됩니다.
그래서 **베르셀 기능에 기대지 않고 비밀번호 문을 직접 만들어 넣었습니다.**
주소로 들어오면 아이디·비밀번호를 묻고, 맞아야만 대시보드가 나옵니다.
무료 플랜에서도 확실히 잠깁니다.

## 어떻게 잠그나

`scripts/build_vercel.py` 가 대시보드를 **작은 프로그램 안에 통째로 집어넣어**
`site/` 폴더를 만듭니다.

```
site/
  api/index.js    ← 비밀번호를 확인하고, 맞으면 대시보드를 내보냅니다
  vercel.json     ← 어떤 주소로 들어와도 위 프로그램을 거치게 합니다
```

대시보드를 그냥 HTML 파일로 두지 않고 프로그램 안에 넣은 이유가 있습니다.
파일로 두면 **베르셀이 그 파일을 비밀번호도 안 묻고 그냥 내줍니다.**
그래서 `site/` 안에는 HTML·이미지 같은 파일을 절대 두면 안 됩니다.

---

## 1단계 — 배포용 폴더 만들기

```
python3 scripts/build.py           # 대시보드 만들기
python3 scripts/build_vercel.py    # 베르셀용으로 감싸기
git add -A && git commit -m "대시보드 갱신" && git push
```

## 2단계 — 베르셀에 올리기

1. https://vercel.com 에서 **Continue with GitHub** 으로 가입·로그인합니다.
2. **Add New… → Project** 를 누릅니다.
3. 이 저장소를 고릅니다.
   - 목록에 없으면 **Adjust GitHub App Permissions** 에서 저장소를 허락해 주세요.
     저장소가 비공개여도 됩니다.
4. 설정을 이렇게 넣습니다. **Root Directory 가 제일 중요합니다.**

   | 칸 | 넣을 값 |
   |---|---|
   | Framework Preset | `Other` |
   | **Root Directory** | **`site`** ← Edit 눌러서 고릅니다 |
   | Build Command | 비워 둡니다 |
   | Output Directory | 비워 둡니다 |

   > `site` 로 지정해야 합니다. 저장소 최상위를 올리면
   > `data/원본/` 의 엑셀(**고객 이름이 들어 있습니다**)이 웹에 그대로 노출됩니다.

5. **Environment Variables** 를 펼쳐서 넣습니다.

   | Name | Value |
   |---|---|
   | `DASHBOARD_PASSWORD` | 원하는 비밀번호 (직접 정하세요) |
   | `DASHBOARD_USER` | 원하는 아이디 (안 넣으면 `admin`) |

   > 비밀번호를 안 정하면 사이트가 열리지 않습니다.
   > 재무 자료가 실수로 공개되는 것보다 안 열리는 게 낫기 때문에 그렇게 만들었습니다.

6. **Deploy** 를 누릅니다. 1~2분 뒤 주소가 나옵니다.
   `https://프로젝트이름.vercel.app`

## 3단계 — 확인

주소로 들어가면 아이디·비밀번호를 묻는 창이 떠야 합니다.
넣으면 대시보드가 보입니다. 창이 안 뜨면 4단계로 가세요.

한 번 넣으면 브라우저가 기억합니다. 다른 사람은 주소를 알아도 못 봅니다.

## 4단계 — 잘 되는지 스스로 점검

브라우저 시크릿 창(Ctrl+Shift+N)으로 주소를 열어 보세요.
**비밀번호를 묻지 않고 대시보드가 그냥 보이면 잘못된 것입니다.**
그 경우 Root Directory 가 `site` 가 맞는지 확인하세요.

---

## 비밀번호 바꾸기

베르셀 → 프로젝트 → **Settings → Environment Variables** →
`DASHBOARD_PASSWORD` 수정 → **Deployments** 탭 → 맨 위 배포의 `⋯` → **Redeploy**.

환경변수는 바꿔도 다시 배포해야 반영됩니다.

## 자료를 새로 넣었을 때

```
python3 scripts/build.py
python3 scripts/build_vercel.py     # 이것도 꼭 같이 돌리세요
git add -A && git commit -m "자료 갱신" && git push
```

푸시하면 베르셀이 알아서 다시 올립니다. 주소는 그대로입니다.

> `build_vercel.py` 를 빼먹으면 사이트 숫자가 안 바뀝니다.
> 대시보드가 `site/api/index.js` 안에 들어 있어서, 그것도 다시 만들어야 합니다.

## 자주 막히는 곳

**비밀번호를 안 묻고 그냥 보여요**
→ Root Directory 가 `site` 가 아닙니다.
   Settings → General → Root Directory 를 `site` 로 바꾸고 Redeploy 하세요.

**"비밀번호가 정해지지 않았습니다" 화면이 나와요**
→ `DASHBOARD_PASSWORD` 를 안 넣었거나, 넣고 Redeploy 를 안 한 것입니다.

**비밀번호를 맞게 넣었는데 계속 물어봐요**
→ 아이디를 확인하세요. `DASHBOARD_USER` 를 안 넣었으면 아이디는 `admin` 입니다.

**숫자가 옛날 것이에요**
→ `python3 scripts/build_vercel.py` 를 안 돌리고 푸시한 것입니다.

**로그인 창을 닫고 싶어요 / 다른 계정으로 들어가고 싶어요**
→ 브라우저가 기억하고 있어서 그렇습니다. 시크릿 창으로 열면 다시 물어봅니다.
