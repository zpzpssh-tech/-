# 대시보드를 나만 보는 사이트로 올리기

`dashboard/index.html` 을 **Cloudflare Pages** 에 올리고, **Cloudflare Access** 로
허락한 이메일만 들어올 수 있게 잠그는 방법입니다. 둘 다 무료입니다.

## 왜 이 방법인가

이 대시보드에는 계정별 매출·원가·광고비·마진이 들어 있습니다.
그래서 "주소를 아는 사람은 누구나" 가 아니라 "허락한 이메일만" 이어야 합니다.

| 방법 | 누가 보나 | 비용 |
|---|---|---|
| GitHub Pages | 주소 아는 누구나 · 구글 검색에도 노출 | 무료 |
| **Cloudflare Pages + Access** | **허락한 이메일만** | **무료 (50명까지)** |
| Netlify 비밀번호 | 아는 사람 모두 | 유료 |

Cloudflare Access 는 사이트에 들어오면 이메일을 묻고, 그 주소로 여섯 자리 숫자를
보내 줍니다. 그 숫자를 넣어야 열립니다. 비밀번호를 따로 외울 필요가 없습니다.

---

## 준비물

- Cloudflare 계정 (무료, 가입 1분) — https://dash.cloudflare.com/sign-up
- 이 GitHub 저장소 (비공개여도 됩니다)

## 1단계 — Cloudflare 가입

1. https://dash.cloudflare.com/sign-up 에서 이메일·비밀번호로 가입합니다.
2. 도메인을 사라는 화면이 나오면 **건너뜁니다**. 필요 없습니다.

## 2단계 — 사이트 올리기

1. 왼쪽 메뉴에서 **Compute (Workers)** → **Workers & Pages** 를 누릅니다.
2. **Create** → **Pages** 탭 → **Connect to Git** 를 누릅니다.
3. GitHub 로 로그인하고, Cloudflare 가 이 저장소를 읽도록 허락합니다.
   - 저장소가 비공개여도 됩니다. 목록에서 안 보이면
     **Add account** 또는 **Configure GitHub App** 에서 저장소를 골라 주세요.
4. 저장소 목록에서 이 저장소를 고르고 **Begin setup**.
5. 설정을 이렇게 넣습니다. **여기가 중요합니다.**

   | 칸 | 넣을 값 |
   |---|---|
   | Project name | `alltogethernow-pnl` (주소가 됩니다) |
   | Production branch | `claude/naver-coupang-dashboard-lk42uw` |
   | Framework preset | `None` |
   | Build command | **비워 둡니다** |
   | Build output directory | `dashboard` |

   > `dashboard` 폴더만 올린다는 뜻입니다. 이렇게 해야 `data/` 안의
   > 원본 엑셀·CSV(고객 이름이 들어 있습니다)가 사이트에 딸려 올라가지 않습니다.

6. **Save and Deploy** 를 누릅니다. 1~2분 뒤 주소가 나옵니다.
   `https://alltogethernow-pnl.pages.dev`

이 시점에는 **아직 주소를 아는 사람은 누구나 볼 수 있습니다.** 3단계를 꼭 하세요.

## 3단계 — 나만 보게 잠그기 (제일 중요)

1. 왼쪽 메뉴 **Zero Trust** 를 누릅니다.
   (처음이면 팀 이름을 정하라고 합니다. 아무 이름이나 넣고, 요금제는 **Free** 를 고릅니다.
   카드 정보를 물어도 무료 요금제면 청구되지 않습니다.)
2. **Access** → **Applications** → **Add an application** → **Self-hosted**.
3. 이렇게 넣습니다.

   | 칸 | 넣을 값 |
   |---|---|
   | Application name | `손익 대시보드` |
   | Session duration | `1 week` (일주일에 한 번만 인증) |
   | Subdomain | `alltogethernow-pnl` |
   | Domain | `pages.dev` |

4. **Next** → 정책(Policy)을 만듭니다.

   | 칸 | 넣을 값 |
   |---|---|
   | Policy name | `대표만` |
   | Action | `Allow` |
   | Include → Selector | `Emails` |
   | Value | `zpzpssh@gmail.com` |

5. **Next** → **Add application** 으로 저장합니다.

이제 주소로 들어가면 이메일을 묻고, 등록한 주소로 온 여섯 자리 숫자를 넣어야 열립니다.
다른 사람은 주소를 알아도 못 봅니다.

### 나중에 직원에게도 보여주려면

Access → Applications → `손익 대시보드` → Policies → `대표만` 편집 →
Value 에 이메일을 줄바꿈으로 추가하면 됩니다. 50명까지 무료입니다.

## 자료를 새로 넣었을 때

```
python3 scripts/fetch_sheets.py     # 구글 시트에서 자료 받기 (쓰는 경우)
python3 scripts/build.py            # 대시보드 다시 만들기
git add -A && git commit -m "자료 갱신"
git push
```

푸시하면 Cloudflare 가 알아서 다시 올립니다. **주소는 그대로입니다.**
1~2분 뒤 새로고침하면 최신 숫자가 보입니다.

## 이 폴더의 파일이 하는 일

| 파일 | 하는 일 |
|---|---|
| `dashboard/index.html` | 대시보드 본체. `build.py` 가 만듭니다 |
| `dashboard/_headers` | 검색엔진 수집 금지, 다른 사이트에서 창 안에 못 넣게 막기 |
| `dashboard/robots.txt` | 검색엔진 수집 금지 (한 번 더) |

## 자주 막히는 곳

**저장소가 목록에 안 보여요**
→ Cloudflare 의 GitHub 앱에 이 저장소를 허락하지 않은 것입니다.
   저장소 고르는 화면에서 **Configure GitHub App** → 저장소 체크 → Save.

**주소로 들어갔는데 이메일을 안 물어요**
→ 3단계 Access 설정이 안 된 것입니다. Subdomain·Domain 이 실제 주소와
   똑같은지 확인하세요. `alltogethernow-pnl` + `pages.dev`.

**빈 화면이 나와요**
→ Build output directory 가 `dashboard` 인지 확인하세요.
   비어 있으면 저장소 최상위를 올려서 `index.html` 을 못 찾습니다.

**숫자가 옛날 것이에요**
→ `python3 scripts/build.py` 를 돌리고 커밋·푸시했는지 확인하세요.
   `dashboard/index.html` 이 바뀌어야 사이트도 바뀝니다.
