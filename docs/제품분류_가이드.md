# 올투게더나우 제품 분류 가이드 (대표 확인, 2026-09-09)

제안서·상세페이지·상담 문구를 쓸 때 이 분류를 기준으로 한다. 대표(물리치료사)가 정리한 내용.

## 1. 무릎 보호대

| 제품 | 핵심 기능/특장점 | 주로 추천하는 경우 | 상대적으로 비추천 |
|---|---|---|---|
| 슬개건 보호대 | 무릎뼈 아래 슬개건을 국소적으로 압박·지지. 작고 활동성이 좋음. 마사지볼 포함 | 슬개건 부위 압통, 러닝·점프·계단·하산 시 무릎뼈 바로 아래 통증 | 안쪽/바깥쪽/뒤쪽 통증, 무릎 전체 불안정 |
| 벡터 무릎보호대 | 슬개골의 움직임과 방향성을 보조. 안쪽 방향 벡터 지지, 초박형 실리콘, 오금 고정 | 앞무릎·슬개골 주변 통증, 계단, 스쿼트, 앉았다 일어나기, 슬개골이 바깥쪽으로 빠지는 듯한 느낌 | 인대성 불안정이나 무릎 전체 흔들림이 주증상인 경우 |
| 자바라 무릎보호대 | 슬개건 + 대퇴사두건을 위·아래에서 지지하는 듀얼 스트랩. 앞무릎을 비교적 넓게 지지하면서 활동성 확보 | 러닝, 반복적인 굽힘·폄, 앞무릎 전체 부담, 슬개건보다 넓게 잡고 싶지만 4세대는 부담스러운 경우 | 명확한 인대 불안정, 반복적으로 무릎이 꺾이는 경우 |
| 베나 니 슬리브 | 슬리브형의 부드러운 압박, 통기성, 편안한 착용감 | 예방, 가벼운 통증, 일상생활, 장시간 착용, 운동 시 가벼운 지지 | 이미 뚜렷한 불안정성이 있거나 강한 지지가 필요한 경우 |
| 4세대 영자무릎 | 좌우 지지대 + X자 테이핑 + 슬개골 오픈. 무릎 전체 안정성 보조 | 안쪽/바깥쪽을 포함한 넓은 통증, 퇴행성·관절염, 인대 병력, 흔들림·꺾임, 등산·장시간 보행 | 슬개건 한 지점의 통증이나 가벼운 예방 목적인데 굳이 강한 지지가 필요 없는 경우 |
| 8세대 영자무릎 | 4세대의 전체 지지 구조 + 슬개건 패드 | 전체적인 불안정성에 무릎뼈 아래/슬개건 부담까지 같이 있는 경우, ACL 수술 후 복귀 등 강한 지지가 필요한 경우 | 단순 앞무릎 통증, 예방 목적, 움직임이 중요한데 불안정성이 없는 경우 |

## 3. 허리 보호대

- **바른요 허리보호대**: 주로 **디스크 패턴**. 옆구리 압박 + 후방 5개·측면 2개 지지대로 허리를 보조하고 복압 형성에 도움. 오래 앉으면 아픔, 앞으로 숙일 때 불편, 물건을 들 때 통증, 반복적으로 허리를 굽히는 작업에 우선.
- **더나은 허리보호대**: 주로 **협착증 패턴**. 복부 전방 압박으로 보행 시 부담 보조. 오래 서 있거나 걸으면 힘듦, 허리를 뒤로 젖히면 불편, 앉거나 앞으로 조금 숙이면 편함, 카트를 밀면서 걸으면 편한 경우에 우선.
- **중급 허리보호대**: 협착증 방향이지만 더나은보다 **움직임을 더 자유롭게** 가져가고 싶은 고객.
- **올바른 허리보호대**: 통기성에 초점을 둔 협착증용 선택지.
- **블랙 허리보호대**: 디스크 패턴의 가성비 좋은 입문형/일상형. 바른요까지 필요하지 않으면서 숙임·앉기·허리 사용 시 부담을 줄이고 싶은 고객.
- **힐링허그**: 구조적 허리보호대가 아니라 복부·허리 온냉 기능을 쓰는 **온열/코어 히팅 제품**으로 구분.

## 문구 작성 시 원칙

1. 제품마다 "추천 패턴"과 "비추천"을 같이 적는다. 무조건 좋다고 쓰지 않는다.
2. 부위·증상 이름은 위 표의 용어(슬개건, 척측, 디스크 패턴, 협착증 패턴)를 그대로 쓴다.
3. 강한 지지(영자 8세대, 고정 손목)와 가벼운 예방(베나, 쫀쫀)을 섞어 쓰지 않는다.
