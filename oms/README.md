# 올투게더나우 통합 주문·재고 관리 (1단계)

네이버 스마트스토어와 쿠팡 4개 계정(올투게더나우·휴책·유큐어·로켓배송)의 주문을 **한 화면에 모으고**,
팔린 만큼 **창고별 재고를 자동으로 빼 주는** 프로그램입니다.

## 실행하기

1. 파이썬이 없다면 설치합니다 → https://www.python.org/downloads/ (설치할 때 *Add Python to PATH* 체크)
2. 이 폴더(`oms`)에서
   - 윈도우: `실행_윈도우.bat` 더블클릭
   - 맥: `실행_맥.command` 더블클릭 (처음 한 번은 우클릭 → 열기)
   - 또는 터미널에서 `python3 oms/app.py`
3. 브라우저가 자동으로 열립니다 → `http://127.0.0.1:8765`
4. 끌 때는 검은 창(터미널)에서 `Ctrl + C`를 누릅니다.

설치할 다른 프로그램은 없습니다. 네이버 실제 연결할 때만 `pip install bcrypt`가 한 번 필요합니다.

처음에는 **데모 모드**로 열립니다. 가짜 주문 30일치가 들어 있어서 마음껏 눌러봐도 됩니다.
(상품명·옵션은 실제 판매 데이터에서 많이 팔린 것을 참고했고, 고객 정보는 모두 가짜입니다)

## 화면 구성

| 메뉴 | 하는 일 |
|---|---|
| 홈 | 오늘 주문, 출고 대기, 미매칭 상품, 재고 경고, 14일 주문 추이 |
| 주문 | 5개 계정 주문 통합 목록 → 발주확인 → 택배 출고파일 → 송장 일괄 입력 → 송장 전송·출고완료 |
| 재고 | 창고 4곳(본사·N배송·그로스 휴책·그로스 유큐어)의 현재고·가용·소진 예상일, 입고·이동·실사 조정 |
| 상품 매핑 | 쇼핑몰 옵션 → 실제로 나가는 SKU와 개수 연결, SKU 관리 |
| 설정 | API 키 입력·연결 테스트, 자동 수집 주기, 데모 모드 켜고 끄기 |

## 핵심 개념 3가지

**1. SKU와 상품 매핑**
SKU는 창고 선반에 실제로 놓인 '낱개 실물'입니다. 쇼핑몰 옵션은 세트일 수 있어서 연결이 필요합니다.

| 쇼핑몰 옵션 | 실제로 나가는 것 |
|---|---|
| 네이버 "블랙 + 마사지볼 / 양쪽" | 무릎보호대 블랙 ×2, 마사지볼 ×1 |
| 쿠팡 휴책 "2개, 블랙" | 무릎보호대 블랙 ×2 |

한 번만 연결하면 이후 주문은 자동으로 재고가 빠지고, 나중에 고쳐도 지난 주문까지 다시 계산됩니다.

**2. 배송 방식에 따라 재고가 빠지는 창고가 다릅니다**

| 배송 방식 | 계정 | 재고가 빠지는 곳 | 언제 빠지나 |
|---|---|---|---|
| 판매자배송 | 쿠팡 올투게더나우, 네이버 일반배송 | 본사창고 | 출고완료 처리할 때 (그전엔 '예약') |
| N배송(도착보장) | 네이버 | 네이버 N배송창고 | 주문이 들어오는 즉시 |
| 로켓그로스 | 휴책, 유큐어 | 해당 계정 그로스 창고 | 주문이 들어오는 즉시 |
| 로켓납품(직매입) | 로켓배송 | 본사창고 | 출고완료 처리할 때 |

본사 → 그로스·N배송창고로 물건을 보낼 때는 **재고 → 창고 이동**으로 등록합니다.
그로스·N배송창고 재고가 7일 안에 바닥날 것 같으면 홈에 **입고필요** 경고가 뜹니다.

**3. 가용재고 = 현재고 − 아직 안 나간 주문 수량**
쇼핑몰에 재고 수량을 올릴 때는 현재고가 아니라 가용재고를 기준으로 하세요.

## 실제 쇼핑몰 연결하기

1. API 키를 받습니다.
   - 네이버: 커머스API센터 → 애플리케이션 등록 → 애플리케이션 ID·시크릿
   - 쿠팡: WING → 판매자정보 → 추가판매정보 → OPEN API 키 발급 (계정마다 따로)
2. 프로그램의 **설정** 화면에 넣고 **연결 테스트**를 누릅니다.
3. 테스트가 성공하면 **데모 모드를 끄고**, 설정 → 데모 데이터 초기화는 누르지 마세요.
4. 데모 SKU 대신 실제 SKU를 **상품 매핑 → SKU 관리**에서 등록하고, **재고 → 실사 조정**으로 실제 수량을 맞춥니다.
5. 첫 수집 후 **상품 매핑**에서 미매칭 상품을 연결합니다.

키는 `oms/설정/계정.json`에만 저장되며 깃(git)에는 올라가지 않습니다. 채팅이나 메신저에 붙여넣지 마세요.

> ⚠ 쇼핑몰 API 연결 코드는 네이버·쿠팡 공개 문서대로 작성했지만, 실제 키로는 아직 시험하지 않았습니다.
> 처음 연결할 때 '연결 테스트'를 먼저 해 보고, 오류 메시지가 나오면 그대로 알려주세요.
> 특히 **로켓그로스 주문 API**는 계정별 사용 신청이 필요할 수 있습니다.

## 아직 안 되는 것 (다음 단계 후보)

- 택배사 송장 자동 발급·출력 → 택배사(CJ 등) 기업 계약 후 연동. 지금은 '택배 출고파일 받기'로 엑셀을 내려받아 택배사 프로그램에 올립니다.
- 로켓배송 발주서 자동 수집 → 오픈API가 없어 '주문 직접 등록'으로 넣습니다. (발주서 엑셀 불러오기는 추가 가능)
- 쇼핑몰 재고 수량 자동 반영, 고객 문의(C/S)·반품 통합, 알림톡
- 24시간 자동 수집 → 지금은 프로그램이 켜져 있는 동안만 10분마다 수집합니다. 항상 돌리려면 클라우드 서버(월 1~3만 원)에 올리면 됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 프로그램 본체. 화면 요청을 받아 처리 (내 컴퓨터에서만 접속 가능) |
| `store.py` | 주문·재고·매핑 장부 (`oms.db` 파일 하나에 저장) |
| `connectors.py` | 네이버·쿠팡 API 연결 |
| `demo.py` | 연습용 가짜 데이터 |
| `static/index.html` | 화면 |
| `설정/계정.json` | API 키와 설정 (처음 실행 시 자동 생성, git 제외) |

데이터를 백업하려면 프로그램을 끈 상태에서 `oms.db` 파일을 복사해 두면 됩니다.
